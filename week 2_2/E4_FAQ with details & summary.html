How do semantic tags improve web accessibility?

The alt attribute provides alternative text for images. Screen readers read it to visually impaired users, and it displays when the image fails to load.

What is the purpose of the head tag in HTML?

The DOCTYPE declaration tells the browser which version of HTML the document uses. <!DOCTYPE html> triggers standards mode for consistent rendering across all browsers.
